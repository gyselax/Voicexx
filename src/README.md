- [geometryMX](./geometryMX/README.md) : Code describing a geometry with a single spatial dimension and a single fluid moment dimension.
- [geometryXNeutrals](./geometryXNeutrals/README.md) : Code describing a geometry in which the neutral grid is different from the plasma grid.
- [reactionrates](./reactionrates/README.md) : Code describing the ionisation, recombination and charge-exchange reactions rates between the plasma and the neutrals.
- [neutralsolvers](./neutralsolvers/README.md) : Solvers for the neutrals transport and plasma-neutrals interactions.

# Geometry (X\_Neutrals)

The `geometryXNeutrals` folder contains all the code describing methods which are specific to a geometry where the grid for the plasma and the grid for the neutral species are different.
It is broken up into the following sub-folders:

- [fluid solvers](./gridneutralfluidsolver/README.md) : Solvers for the neutral equation.
- [geometry](./geometry/README.md) : Aliases to work with this new grid.

# Geometry X\_Neutral

The geometry folder contains a helper file `geometry_neutrals.hpp` which provides aliases to the types needed to define the specific geometry.
In this case the geometry is a simulation with 1 spatial dimension (denoted XNeutrals) on which the neutral species are defined.
For more detailed informations, see [geometryXVx](../../../gyselalibxx/src/geometryXVx/geometry/README.md).
